# Alertsify live performance dashboard

## Register

Product UI (dense trading dashboard), not marketing.

## Tone

Professional, calm, data-first. No hype copy.

## Layout

- 8px spacing grid; max content width ~1280px
- Overview KPI row, then charts, then full-width trades table
- Sticky table header on scroll

## Typography

- UI: "IBM Plex Sans", system-ui fallback
- Monospace for symbols, order IDs, premiums: "IBM Plex Mono"
- Modular scale: 12 / 14 / 16 / 20 / 24 / 32

## Color (OKLCH)

- Surface: oklch(98% 0.01 250)
- Surface elevated: oklch(100% 0 0)
- Text primary: oklch(22% 0.02 250)
- Text muted: oklch(48% 0.02 250)
- Border: oklch(88% 0.02 250)
- Accent (live badge only): oklch(52% 0.14 250)
- Profit: oklch(45% 0.12 155)
- Loss: oklch(48% 0.14 25)

## Do not

- Inter, purple gradients, nested card stacks
- Gray text on tinted backgrounds
- Decorative motion; respect prefers-reduced-motion

## Components

- KPI stat blocks with label + value + delta
- Sortable data table with zebra optional
- Line chart equity curve; bar chart by underlying
- Skeleton loaders; empty state when no live trades
